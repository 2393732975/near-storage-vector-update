# Compute-node 背景数据移动实验报告（2026-09-23）

## 结论

本轮完成 GIST1M、Text2Image10M、Deep100M 和 SIFT100M 四组 compute-node
背景实验，共成功更新 13,236 次，`failed_updates=0`，无 RADOS 重试或 label
冲突。候选向量搬运占距离阶段的 98.15%–99.78%，本地距离计算只占
0.18%–1.80%，验证了 PPT 背景实验的核心判断：传统计算侧更新的距离阶段主要
成本是数据移动，而不是距离算术。

与答辩 PPT 的计算节点吞吐相比，本轮四个数据集分别提高 74.7%–215.4%。由于
代码、协议、Ceph 状态和机器负载均已变化，这只能说明当前实现与环境下的复现
结果，不能解释为单一优化带来的收益。

## 有效性限制

- 本轮每个数据集只运行一次，尚无独立重复样本、标准差或置信区间。
- `run-ppt-baselines.sh` 不执行离线一致性检查；本轮零失败，但还不能替代阶段 0
  runner 的图一致性验收。
- 本轮只有 compute 路径。不能与不同日期的 OSD 结果形成严格 A/B；正式对比应在
  同一提交和集群状态下交错运行 `compute osd`，至少重复三次。
- 结果目录最初由一次中止的误启动创建；正式重启前相关进程已终止，runner 重新
  创建了全部实验池并覆盖四个数据集工件。后续正式实验应始终使用新的 `RUN_ROOT`。
- 运行结束时全部 PG 为 `active+clean`，但集群仍有既有 BlueStore slow-op 和
  devicehealth 磁盘 I/O 告警；这些告警未被屏蔽。
